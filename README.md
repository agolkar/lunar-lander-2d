# Lunar Lander 2D

A classic lunar lander game in a single HTML file, with no libraries and no build step.

**Play:** https://agolkar.github.io/lunar-lander-2d/

## How it was built

Built from [Ivan Fioravanti's lunar lander prompt](https://gist.github.com/ivanfioravanti/7df44346f7d3d5e5d7e993c1dc51a3ce), which he uses to compare how models handle the same task. This version was generated by DeepSeek V4.1 Flash running on-premise on a Mac Studio M3 Ultra, from an extended version of that prompt.

A 3D version, built in stages the same way, is at https://agolkar.github.io/lander3d/
